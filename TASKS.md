# Sprint Backlog — Gerenciador Financeiro

## Objetivo do projeto

Desenvolver um sistema web simples para gerenciamento de finanças pessoais, permitindo cadastrar receitas e despesas, consultar movimentações e visualizar o saldo disponível.

## Sprint 1 — Planejamento e estrutura inicial

**Objetivo:** Organizar o projeto e desenvolver a interface inicial.

- [x] Definir o tema do projeto.
- [x] Escolher as tecnologias utilizadas.
- [x] Criar a pasta e os arquivos do projeto.
- [x] Desenvolver a estrutura HTML.
- [x] Criar a estilização com CSS.
- [x] Desenvolver a interface de receitas, despesas e saldo.

**Resultado:** Interface inicial do Gerenciador Financeiro desenvolvida.

**Objetivo:** Implementar as funcionalidades principais do sistema.

- [x] Criar listagem de movimentações.
- [x] Implementar exclusão de movimentações.
